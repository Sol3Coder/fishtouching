# 终端小说阅读器 · 交互规格

交付目标：Rust / ratatui 终端程序的交互设计，不是网页产品。`screens.html` 只是五张终端稿的展示载体，不模拟浏览器按钮。所有图都是 **80列 × 24行**，含外框；中文宽字符占2列，框线占1列。数值、进度、书源编号均为明确标记的演示数据；正文为排版说明，不冒充原著。没有联网数据依赖。

## 1. 信息架构与关键决策

只有五种页面：书架、搜索、目录、阅读、书源。同一时刻只渲染一种页面；帮助、输入、确认是当前页面的临时模式，替换其内容区，不新增导航节点、不并列面板。

- 主路径：书架 → 目录 → 阅读。书架 Enter **进入目录并选中上次阅读章节**，再 Enter 阅读并恢复该章滚动锚点；不偷偷绕过目录。这是“逐屏进入”与“恢复上次章节”的明确取舍。
- 新书路径：书架 → 搜索 → 目录 → 阅读。目录记住来源为搜索，逐级 Esc 可以原路退回。
- 书源路径：书架 → 书源。书源只从书架进入，不开放随处跳转，避免丢失导航上下文。
- 书架是集合，不是历史本身。打开并成功取得非空目录才算“打开成功”，此时幂等自动收录；仅加载失败、仅高亮不收录。阅读加载成功也执行同一幂等收录，覆盖移出后的再次打开场景。
- 搜索结果 b 是“加入书架”，不打开、不切换页面；已在书架时为幂等无操作，提示“已在书架”。移出只在书架 d 完成，没有“收藏/书签/书架”三种概念混用。
- 阅读位置独立保存：书籍身份、章节身份、正文段落/字素偏移、最近成功打开时间。仅高亮目录不更改进度。移出书架不删历史，重新打开仍恢复位置。
- 自动收录写入失败时不报“已加入”；目录仍可查看，状态标“书架保存失败”，保留待重试操作。不得误将加载成功当成持久化成功。

### 数据身份

书源使用持久化 ID；书籍使用书源 ID + 规范化书籍 URL；章节优先使用规范化章节 URL。跨书源同名书不合并阅读历史，搜索结果始终显示来源。章节 URL 不存在时使用源内章节键并记录序号作为降级定位。目录更新后先匹配键，再匹配唯一同名章；均失败则夹取旧序号到合法范围并提示“章节已变更，请确认”，不静默声称精确恢复。

## 2. 导航图与返回契约

```text
书架 ──Enter──> 目录(origin=书架) ──Enter──> 阅读
  ^               │                         │
  └────Esc────────┘              Esc 回同一本目录

书架 ── / ──> 搜索 ──Enter(结果)──> 目录(origin=搜索) ──Enter──> 阅读
  ^             ^                     │                       │
  └──Esc────────┘                     │          Esc 回同一本目录
                └────────Esc──────────┘

书架 ── s ──> 书源
  ^             │
  └────Esc──────┘

任一页面 ──F1──> 帮助模式 ──Esc──> 同一页、同一焦点
列表/正文 ──g、a、Enter等──> 输入/确认模式 ──Esc──> 同页原焦点
书架 ──q / Ctrl-C──> 退出确认 ──Enter(选择退出)──> 退出
```

导航栈保存页面状态，不只保存枚举名称。阅读 n/p 替换当前阅读章节而不 push；阅读 g 成功也是替换，因此 Esc 永远回目录而非前一章。阅读返回时，目录选择当前最后成功显示的章节；搜索返回时恢复关键词、结果顺序、选中 ID、列表顶行和结果焦点。书架返回时恢复选中书籍与顶行。

**防止“回不去”的坑：**

1. 搜索打开书后不能把目录父级硬编码成书架，否则原结果丢失；必须保留 origin。
2. 返回搜索不自动重新查询，不清空列表。异步回调不得重新 push 已离开的目录或阅读页。
3. 目录是加载中/空/出错也能 Esc；立即取消对应任务或忽略其结果并返回父级，不先吞一次 Esc 只取消网络。
4. 页面内输入模式先 Esc 取消输入，再 Esc 离开页面；其提示行必须写“取消”，不能写“返回书架”。搜索关键词是常驻焦点区，**不是临时输入模式**，Esc 直接返回书架。
5. 根书架 Esc 不退出，状态提示“已在书架，q 退出”；不创建虚假父页面。
6. 编辑未保存时 Esc 进入“保留编辑/放弃修改”确认，默认保留；这属于显式的脏数据保护，确认后才关闭输入模式。再 Esc 才离开书源。
7. 搜索期间打开结果会取消尚未完成的查询，保留已取得结果；返回显示“搜索已停止”，不在后台改动列表。目录失败不会自动收录。

## 3. 终端构图与焦点

固定80×24参考画布。第1/24行外框；第2行标题；第3行路径/返回目标；第4行分隔；第5–20行内容；第21行分隔；第22行状态；第23行按键提示。内宽78列。页面名和正文使用亮白，标签/边框/次要状态用灰，唯一焦点用黄，按键名用青。颜色为16色语义，不以 hex 定义颜色真相；终端调色板决定具体 RGB。

ratatui 配色意图：背景 Black、正文 White（亮白）、次要 Gray（灰）、焦点 Yellow（黄）、按键 Cyan（青）。HTML 以同名 CSS 颜色近似，只设置字体/前景/背景；不使用 CSS 布局、按钮、hover、圆角、阴影、渐变、图像。无论主题如何映射，必须保留 `>`、`[x]`、`[ ]`、焦点状态文本等非颜色标记。使用 CJK 等宽回退字体，禁止字体连字。HTML 字号18px，不压缩成移动网页；小视口由浏览器自然横向查看固定80列稿。

选中行以 `>` 前缀和黄色整行表达；失焦列表保留选择但取消黄色。文本输入焦点用终端光标和黄色字段标签表达，示意稿中的 `_` 为光标，非已输入字符。任一时刻只有一个焦点拥有者。帮助、确认模式也必须有状态行和键提示。状态行优先显示错误、任务状态，再显示计数；超长状态截断，F1 帮助中的“当前状态”显示完整诊断，Esc 返回原焦点。

## 4. 按键原则与分发优先级

优先级：**Ctrl-C / F1 → 当前临时模式 → 文本输入焦点 → 本屏命令 → 无操作**。Ctrl-C 发起安全退出，F1 打开/关闭帮助，两者是唯一跨模式保留键。帮助显示时先由帮助处理滚动和 Esc。所有键名区分大小写；无必须依赖 Shift 的字母命令。

| 范围 | 按键 | 行为 |
|---|---|---|
| 全局 | F1 | 显示上下文帮助；再按 F1 或 Esc 关闭，恢复原焦点 |
| 全局 | Ctrl-C | 发起退出确认，默认“取消”；有草稿时说明未保存修改 |
| 非输入常规模式 | ? | F1 的便利别名；文本输入时只插入问号 |
| 页面层级 | Esc | 关闭最内层临时模式，否则退回父页面；根页不退出 |
| 各列表 | ↑/↓、j/k | 移动一项；j/k 仅非输入焦点有效 |
| 各列表 | PgUp/PgDn | 移动一个可见项目页，保留目标项可见 |
| 各列表 | Home/End | 第一项/最后一项；输入中改为行首/行尾 |
| 支持重试的非输入模式 | r | 重试状态行指明的失败任务；正常态不执行、不重渲染 |

没有全局 q、S、b、o、r 或数字开关。q 仅书架主模式退出，其余页不触发退出。字母在输入焦点一律作为文本，包括 q、s、b、j、k、r、g、?、数字、斜杠；空格也是文本。Ctrl-C 不作为文本复制键。F1 的终端序列若不可用，非输入模式 ? 仍可访问帮助。

### 输入与确认共用规则

- 文本：左右移动光标；Home/End 到字段首末；Backspace/Delete 按字素删除；Ctrl-U 清空当前字段。输入法提交和 bracketed paste 作为文本事件，不拆成命令；粘贴换行在单行输入中变为空格，不自动提交。
- 搜索框：Enter 查询；Tab/Shift-Tab 往返结果；↑/↓不偷换焦点。空查询只报就地校验错误，不发请求。
- 三字段编辑：Tab/Shift-Tab 在名字、网址、搜索网址循环；Enter 校验并保存全部字段；Esc 取消。字段为空/非法时保留草稿并定位错误字段。
- 确认：左右键/Tab 切换文字选项，Enter 确认；Esc 取消。破坏性操作默认取消，不用单键 y/d 连击直接删除。
- 临时模式占用当前内容区，不画新页面、不并列列表。父页面选中项/滚动位置保持不变。所有异步执行和确认都防重复提交。

## 5. 原按键表的问题与替换

| 原设计 | 问题 | 本方案 |
|---|---|---|
| 全局 q / Ctrl-C 都立即退出 | 输入小说名或 URL 时 q 抢键；丢草稿、进度 | q 仅根书架；Ctrl-C 全局退出确认并保存位置 |
| 全局 S，搜索 s | 大小写难发现；输入中 S 应是文字；跨页跳转破坏栈 | 书架 s 书源、/ 搜索，无全局跳页 |
| Esc 返回未区分层次 | 搜索框、请求中、编辑中含义不明；可能吞键或返回错入口 | 关闭最内临时模式/退父页；常驻搜索输入不增层 |
| 搜索打字 + 结果快捷键 | 两处同时响应会把 b/j/k 当输入又当命令 | 唯一 focus=keyword/results；Tab 显式切换 |
| b 全局收藏，结果加入 | 收藏、书架、书签语义混乱，幂等性不明确 | b 仅搜索结果“加入书架”，已加入不移出 |
| Enter 打开书架书 | 直读与“书架→目录→阅读”冲突 | 进入目录并定位已读章，再 Enter 恢复阅读 |
| 1–9 全局开关第 N 个书源 | 排序后目标变动、只管9条、误伤输入/跳章 | 书源列表 Space 切换当前 ID，支持筛选 |
| 书源 Enter/空格都开关 | 浪费 Enter 的“打开详情/编辑”语义 | Space 开关，Enter 统一进入三字段编辑 |
| 书源 e/u/s 各改一字段 | 模式隐蔽、快捷键太多、s 易混搜索 | 单一表单编辑三个字段，Tab 换字段 |
| 全局 o 打开阅读页 | 无正文时目标不明确，终端失焦可能看似卡死 | 只在阅读正常态 o，先确认 URL 和外部打开风险 |
| 全局 r 重渲染 | 暴露实现细节；易被理解为刷新内容 | 尺寸变化自动重排，r 只重试失败任务 |
| n/p 与方括号重复 | 无必要多套记忆；中英文输入影响方括号 | 保留 n/p，去掉方括号 |
| Home/End 与逗号/句点重复 | 标点误触；输入模式下含义混乱 | 列表 Home/End 首末项，正文章首末；去掉标点别名 |
| g 未描述输入模式 | 数字抢全局源开关、0/越界如何处理不明 | 临时跳章输入，合法范围1…章节总数，Esc 取消 |

## 6. 五屏常规布局、按键与状态

下列每个代码框都是完整80×24屏幕。空/加载/出错均保留路径、状态行与可返回的键提示。状态示例是演示，不表示真实运行结果。

### 01 书架

焦点：只在书籍列表。Enter 将目录选中项设为历史章，尚未读过则首章；不隐式直接进阅读。

| 按键 | 行为 |
|---|---|
| ↑↓ / j k；PgUp/PgDn；Home/End | 逐项、逐页、首末书 |

| d | 确认移出选中书，默认取消；不删除历史或书源 |
| q | 安全退出确认 |
| Esc | 不退出，提示已在书架 |
| r | 只在载入/持久化失败时重试状态行对应任务 |
| F1 / ?、Ctrl-C | 帮助、安全退出确认 |

移出后选择下一项，末项被移出则选上一项；全空时选择为 None，不留下幽灵高亮。自动收录按最近成功打开排序，返回书架时以 ID 恢复选中而非旧索引。

### 02 搜索

焦点：关键词 / 结果二选一。首次进入为关键词；Enter 搜索后焦点仍在关键词，不因异步返回抢焦点。示意稿展示用户已经 Tab 到结果后的状态。空结果也可切到结果区，但 Enter/b 均提示无可操作项。

| 焦点 | 按键 | 行为 |
|---|---|---|
| 关键词 | 文字及粘贴 | 只编辑草稿，不自动发请求 |
| 关键词 | Enter | 以草稿发起查询；相同查询进行中不重复提交 |
| 两者 | Tab / Shift-Tab | 在关键词与结果间切换 |
| 结果 | ↑↓ / j k；PgUp/PgDn；Home/End | 逐项、逐页、首末结果 |
| 结果 | Enter | 保存搜索快照，进入目录；目录非空成功后自动收录 |
| 结果 | b | 手动加入书架，不改变页面或历史章 |
| 结果 | r | 只重试失败源或当前保存失败的操作 |
| 两者 | Esc | 取消当前查询并回书架，不先清关键词 |
| 两者 | F1、Ctrl-C | 帮助、安全退出确认；? 只在结果焦点是帮助 |

### 04 阅读

焦点：正文，没有可同时输入的第二个区域。上下键滚动而非选择章节。标题固定，正文折行只占内容区；一页16行，PgUp/PgDn 移动15行保留1行上下文，达到边界夹取而不跨章。

| 按键 | 行为 |
|---|---|
| ↑↓ / j k | 逐行滚动；当前章边界提示，不跨章 |
| PgUp/PgDn | 上下翻页，保留1行 |
| Home/End | 当前章正文首/末，不是整本首末章 |
| n / p | 下一章 / 上一章；边界提示，无循环 |
| g | 临时章号输入；Enter 加载指定章，成功后替换阅读页 |
| o | 正常正文态确认后调用系统程序打开当前章原始 URL |
| Esc | 回同书目录，选中最后成功显示的章 |
| r | 正文获取/阅读位置保存失败时重试对应任务 |
| F1 / ?、Ctrl-C | 帮助、安全退出确认 |

换章加载时保留旧正文与旧位置，状态明确“正在获取第 N 章”；锁定 n/p/g/o，防止请求堆积，滚动旧正文仍有效。成功后才提交新章；失败仍显示旧章，r 重试目标章，n/p 按最后成功章计算。首次加载没有旧章时显示加载稿。正文为空不记已读。章末显式提示“本章结束，n 下一章”；最后一章提示“已到目录末章”，不能推断连载书已完结。

位置以段落/字素锚点保存而非渲染行号，窗口改变重新折行后仍恢复同一文本附近；滚动停止后300ms合并写入，离开阅读与退出前强制提交，失败提示且保留脏记录。状态只有持久化成功才显示“位置已保存”。退出确认发现保存失败时停留，提供“重试保存/取消退出/放弃未保存位置并退出”，默认取消，不能悄悄退出。

o 只接受当前源给出的有效 http/https 原文 URL，不猜 URL，不输出 JavaScript 或本地可执行路径；系统程序失败留在阅读页提示。外部程序返回后恢复阅读锚点。正文不存在、URL 缺失、加载中时不允许 o。

### 05 书源

焦点：列表 / 筛选输入 / 导入输入 / 三字段编辑 / 确认模式中恰好一个。列表选中和是否启用是不同维度：> 表示焦点项，[x]/[ ] 表示启用。

| 模式 | 按键 | 行为 |
|---|---|---|
| 列表 | ↑↓ / j k；PgUp/PgDn；Home/End | 逐项、逐页、首末源 |
| 列表 | Space | 切换选中源启用状态，原子保存；失败回滚 |
| 列表 | Enter | 进入统一编辑：名字 / 网址 / 搜索网址 |
| 列表 | a | 导入输入模式，支持本地路径或 http/https URL |
| 列表 | d | 删除确认，显示源名与受影响书架数量；默认取消 |
| 列表 | / | 筛选输入模式，Enter 应用、Esc 放弃草稿 |
| 列表 | Esc | 返回书架；已应用筛选不增加隐藏返回层 |
| 列表 | r | 仅失败态重试状态行对应任务 |
| 任一 | F1、Ctrl-C | 帮助、安全退出确认 |
| 非输入 | ? | 帮助别名 |
| 编辑 | Tab/Shift-Tab、Enter、Esc | 换字段、校验保存、取消/放弃确认 |
| 导入/筛选 | Enter、Esc | 提交、取消；不触发列表行为 |

筛选匹配源名与网址，回列表后状态显示“筛选：词；匹配 M / 总数 N”；/ 后 Ctrl-U、Enter 清筛选。筛选无结果与全库为空有不同提示。关闭最后一个源给非阻塞提示“未启用书源，搜索不可用”，不禁止合法配置。

编辑只改 JSON 的 bookSourceName、bookSourceUrl、searchUrl 三字段，保留其他原始字段及规则；不提供“改脚本”能力。名字非空；网址为合法 http/https 基址；搜索网址是 legado 规则文本，可含模板/参数，不把它误判为必须能直接请求的纯 URL；空值表示不支持搜索，需说明。源身份 ID 不随网址编辑改变；旧书记录保留，若链接不兼容显示错误而非删历史。

导入：输入 → 异步读取/解析 → 内容区摘要（有效、新增、重复、无效）→ 确认导入/取消。重名不视为同源；规范化 bookSourceUrl 用于重复识别，默认跳过，覆盖必须显式选择并再次确认。无效项显示索引和原因，不整批静默丢弃。摘要预览只解析，不执行书源 JS。导入警告“书源可执行脚本，仅导入可信来源”，确认前不写文件；成功回列表选中新导入第一项，零新增保留原选择。

读取导入内容期间 Esc 取消任务回列表，只有短暂原子提交阶段完成/失败后才处理返回，状态注明“正在保存”。删除书源不级联删书架和阅读记录；关联书籍显示“书源缺失”，有缓存则可离线读，无缓存可退回而不死锁。重新导入同一规范化 URL 时可恢复关联；禁用源只排除搜索，打开其旧书需要明确提示“书源已停用”，不得静默联网。

## 7. 长内容与性能交互契约

### 3000章

目录只渲染可见行，选中索引和列表顶行分离，保持选中项可见；不让3000行全部挤入画布。Home/End 常数步定位，g 直接定位章号；状态始终给“选中 X / 3000”。单行章名按显示宽度截断为末尾省略号（占1列的三个 ASCII 点则占3列，必须统一选一种；本方案用 `...`），完整选中章名可在 F1 当前项信息中折行查看。目录页有列表表头，实际页容量从内容高度扣除表头与空行后计算，不硬编码16项。

### 几百条结果

用结果 ID 追踪选择，不用字符串标题或位置；按到达顺序稳定追加，显示已返回/失败/总源数。源内相同书籍 URL 去重，跨源同名保留。Tab、Esc 和移动不能等待 JS/网络。仅渲染视口；后台任务必须在取消令牌和查询代际下提交。返回搜索用快照，不重新排序。长标题/作者按列截断，当前项完整详情可在 F1 内查看。

### 3900条书源

首屏不试图给每条分配数字热键。/ 筛选名称或网址，列表 Space 开关当前源；状态给“匹配 M / 总计3900，已启用 E”。筛选索引与显示列表分开，保留稳定源 ID；筛选草稿 Enter 才应用，不每键读磁盘。存储更新以事务/原子替换提交，失败恢复原开关状态。删除后选择最近相邻项，过滤后无项则 None。

### 正文与终端边界

正文以字素簇遍历并按终端显示列折行，不能用 UTF-8 字节长度或 Unicode 字符数量作列宽。CJK宽字符2列，组合附加符0列，框线按1列；歧义宽度默认1列并允许运行配置适配终端。Tab 展开为空格，控制序列/ANSI/OSC 在进入显示层前过滤，书源文字不能控制终端。单词或超长 URL 可按字素硬换行，不越过右框；宽字符在行尾只剩1列时移到下一行。

80×24是本次交付标准，不意味着锁死程序大小。更大窗口扩展同一页内容区；更小终端保持单页，优先保留标题、状态、返回提示，减少内容行和表格列；小于40×12显示“窗口过小，请调整到至少40×12”，仍响应 F1/Ctrl-C/Esc。这里不提供网页式移动端。尺寸事件自动重排，不占用 r。

QuickJS与网络执行不阻塞绘制/按键线程。需为源请求与脚本设置独立的可配置超时、资源预算和取消路径；这是一项实现验收要求，不假定 QuickJS 本身已经安全隔离。搜索设置有界并发，3900条源不能同时执行3900份脚本。不要承诺未验证的 JS 兼容率。错误面向用户给任务、源名、原因、重试动作，不把日志堆栈挤进状态栏；完整诊断在上下文帮助查看并对敏感 URL 参数脱敏。

仍沿用80×24外框，内容区替换为以下文本；父列表不会与表单同时抢焦点。此处是字段清单而非额外屏幕稿。

## 9. 逐屏冲突自查与验收

| 屏/模式 | 可能冲突 | 裁决结果 |
|---|---|---|
| 书架 | s 搜索还是书源；q 输入还是退出 | / 搜索，s 书源；没有文本框，q 退出确认 |
| 搜索输入 | b/j/k/q/r/?/数字是否命令 | 全部文字；仅 Tab、Enter、Esc、F1、Ctrl-C 及编辑键保留 |
| 搜索结果 | Enter 查询还是打开；b 是否取消收藏 | Enter 只打开目录；b 只幂等加入 |
| 目录 | g 后数字是否源开关；Home/End 章还是行 | 数字进入章号；列表首末章；输入字段首末 |
| 阅读 | Home/End 整本还是本章；n/p 是否入导航栈 | 本章首末；换章替换当前阅读页 |
| 书源列表 | Enter 与 Space 是否同义；s 是否编辑 | Enter 编辑，Space 开关；s 无动作 |
| 书源编辑 | Space/j/k/s 是否列表命令 | 都是文字，焦点只在当前字段 |
| 全部 | Esc 取消任务还是退页；r 重渲染还是重试 | 页面任务随退页取消；模式先取消；r 仅明确失败任务 |
| 加载态 | Enter 连击、多次换章、晚响应 | 幂等/禁用重复操作；请求代际阻止回流导航 |

### 可执行验收路径

1. 书架 / → 输入含 `q b s j k ? 123` 的关键词：不能退出、收藏或切源；Enter 查询后 Tab 到结果。
2. 结果 Enter → 目录成功并自动收录 → Enter 阅读 → n → Esc：目录选中新章；再 Esc：回原搜索结果；再 Esc：书架出现该书。
3. 从书架再次 Enter：目录选中历史章；Enter：恢复正文锚点；不需要重翻27章。
4. 搜索结果 b 两次：只加入一次；书架 d 取消不改变集合；确认移出后再次打开自动收录且恢复历史。
5. 目录或阅读加载中 Esc：立即回父级；晚到结果不得把用户拉回已离开的页面。
6. 目录 g 输入0/3001/非数字：错误就地显示，Esc 回目录，章节与进度不变。
7. 书源 / 筛选后 Space：只切换所选稳定 ID；Enter 编辑输入网址含 s/u/e/?：不能触发其他命令。
8. 编辑未保存 Esc：先询问放弃，默认保留；确认放弃后回列表，再 Esc 书架。
9. 阅读记录保存失败后 Ctrl-C：不显示“已保存”，不静默退出；可以取消退出、重试或明确放弃。
10. 全部20张（五屏常规 + 15张状态）逐行检查24行、80显示列；边框连续，无中文宽度挤破列。
